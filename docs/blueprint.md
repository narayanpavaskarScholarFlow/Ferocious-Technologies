# **App Name**: TOOLROOM2.0

## Core Features:

- Tool Catalog Display: Browse and view a comprehensive catalog of all stored tools and resources with their essential details.
- Tool Management (CRUD): Add new tools with detailed attributes, edit existing tool information, and remove obsolete tools from the catalog.
- Smart Categorization & Tagging Tool: An AI assistant that processes tool descriptions to intelligently suggest relevant categories and descriptive tags for efficient organization and discoverability.
- Advanced Search & Filtering: Utilize powerful search functionality and multiple filter options to quickly locate specific tools by name, category, tags, or other defined attributes.
- User Authentication & Profiles: Secure user login to access personalized tool inventories and manage individual settings.

## Style Guidelines:

- Dark color scheme for a sophisticated and focused, high-tech aesthetic.
- Primary color: A cool, muted blue (#3488B2) to convey precision and modernity.
- Background color: A very dark, desaturated blue-gray (#161B1D) that is visibly derived from the primary hue.
- Accent color: A vivid, slightly brighter purple-blue (#5269E1) for calls to action and emphasis, providing a clean contrast against the darker backdrop.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-inspired feel. Body text font: 'Inter' (sans-serif) for clear readability and a neutral, objective tone.
- Code snippets or technical identifiers should use 'Source Code Pro' (monospace).
- Use clean, geometric line icons that are minimalistic and functional, reinforcing the toolroom's theme of efficiency and clarity.
- Modular and organized layouts with clear card-based displays for tools, allowing for easy scanning of information and a structured content presentation.
- Subtle, smooth animations for transitions and feedback (e.g., loading states, item additions) to enhance the user experience without being distracting, maintaining a professional feel.
